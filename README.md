# IA - Evolução dos Prompts

Guia interativo, em um único arquivo HTML, sobre como pedir ao Claude sem "manual de estagiário": pedido, contexto e exemplo, nível de esforço, diagnóstico de erros e checklist.

Base: documentação oficial da Anthropic, consultada em nov. 2026. A documentação muda por modelo; confirme a versão atual.

## Como usar

Abra o site publicado no GitHub Pages ou baixe o `index.html` e abra no navegador. Não há dependências externas.
